## 🎨 About Presensio templates

**Presensio templates** is a free, open-source project template designed with a striking **Neobrutalism** aesthetic. Created by **TechisMology**, this free UI template combines the blazing speed of ViteJS with the utility-first power of Tailwind CSS v4, perfect for building modern web applications quickly.

What makes Presensio templates unique is its approach to UI components. It brings the familiar, developer-friendly component structure of **Bootstrap** (like cards, modals, buttons, alerts, and forms) but is built entirely using highly customized Tailwind CSS v4 and CSS. This gives you the best of both worlds: the ease of use of Bootstrap components with the modern design, performance, and flexibility of a Tailwind v4 template.

## 🚀 Features

- **Neobrutalism Design:** Bold colors, sharp shadows, and high-contrast borders for a standout look.
- **ViteJS:** Lightning-fast development server and optimized production builds.
- **Tailwind CSS v4:** Powered by the latest version of the popular utility-first CSS framework.
- **Bootstrap-like Components:** Pre-built, customizable UI components (Buttons, Modals, Cards, Alerts, etc.) built with custom CSS layers (check out `src/assets/*.css`).
- **Free & Open Source:** A completely free UI template to kickstart your next web project.

## 📦 Getting Started

Follow these steps to get the project up and running on your local machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### 1. Installation

Navigate to the project directory and install the required dependencies:

```bash
# Install dependencies
npm install
```

### 2. Development

Start the ViteJS development server:

```bash
npm run dev
```

The application will be accessible at `http://localhost:5173` (or the port shown in your terminal).

### 3. Production Build

To create an optimized production build, run:

```bash
npm run build
```

The compiled output will be generated in the `dist` folder, ready to be deployed.

## 🧱 Component System

Presensio templates uses a component structure heavily inspired by Bootstrap. Inside the `src/assets/` directory, you will find dedicated CSS files for each component type (e.g., `button.css`, `modal.css`, `card.css`, `alert.css`). 

These files contain custom neobrutalist styles that integrate perfectly with Tailwind CSS v4. You can use these pre-defined classes in your HTML to rapidly build interfaces, maintaining a consistent Bootstrap-like workflow but with a radically different design language.
